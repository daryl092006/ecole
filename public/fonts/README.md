# Nunito Sans web fonts

Nunito Sans is the free fallback for devices without Avenir. Avenir remains the first font in the application stack.

Source: Google Fonts, Nunito Sans v19, downloaded on 2026-10-14.

- Catalogue: https://fonts.google.com/specimen/Nunito+Sans
- License: https://github.com/google/fonts/blob/main/ofl/nunitosans/OFL.txt
- Original assets: https://fonts.gstatic.com/s/nunitosans/v19/

The four WOFF2 files contain Latin and extended Latin characters, normal and italic styles, and variable weights from 200 to 900. Preserve OFL.txt when distributing these files. The application and print documents both use nunito-sans.css; font requests stay on the application origin.
